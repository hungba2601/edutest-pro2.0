Đồng bộ danh bạ máy chủ để học sinh tự động đăng nhập
📘 Hướng dẫn 5 bước thiết lập Google Sheet & lấy link Web App:
1. Bấm nút Sao Chép Mã Code (.gs) màu xanh bên dưới.
2. Mở Google Sheet ➔ Chọn Tiện ích mở rộng ➔ Apps Script.
3. Xóa hết code cũ, dán code mới vào (Ctrl + A rồi Ctrl + V) ➔ Bấm Lưu (Ctrl + S).
4. (Tạo 5 Sheet tự động): Trên thanh công cụ Apps Script, chọn hàm initDatabase ➔ Bấm nút Chạy (Run / ▶️).
👉 Code sẽ tự tạo đủ 5 Sheet dữ liệu. (Nếu Google hỏi cấp quyền: Chọn Nâng cao ➔ Đi tới dự án ➔ Cho phép).
5. (Lấy link Web App): Bấm Triển khai ➔ Tùy chọn triển khai mới (hoặc nếu đã có sẵn thì chọn Quản lý bản triển khai ➔ Biểu tượng bút Sửa ➔ Phiên bản mới):
  • Loại: Ứng dụng web | Thực thi: Tôi (Me)
  • Ai có quyền truy cập: Bất kỳ ai (Anyone)
➔ Bấm Triển khai ➔ Copy URL ứng dụng web dán vào ô bên dưới!

👉 Các bước cập nhật nhanh:

  3. Nhấn Ctrl+A rồi Ctrl+V dán đè toàn bộ mã mới vào file Code.gs.
  4. Bấm Triển khai (Deploy) -> Quản lý bản triển khai (hoặc Triển khai mới) để kích hoạt phiên bản mới!
