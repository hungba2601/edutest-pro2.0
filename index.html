Google Apps Script Web App URL

Dán địa chỉ Web App của file Google Sheets cá nhân. Sau khi kết nối, bạn sẽ đăng nhập bằng chính tài khoản có trong Sheet của mình.

ℹ️
Trạng thái kết nối Google Sheet
Bấm "⚡ Kiểm tra kết nối Sheet" để kiểm tra tín hiệu tới Web App.
Hướng dẫn tự tạo Backend riêng (chỉ mất 2 phút):
  1. Tạo 1 file Google Sheet mới > Vào menu Tiện ích mở rộng > Apps Script.
  2. Bấm nút "📋 Sao chép mã nguồn Code.gs" ở trên rồi dán đè vào Apps Script. Nhấn Ctrl + S để lưu.
  3. Chọn hàm initDatabase và bấm Chạy (Run) một lần để tự động khởi tạo các bảng và tài khoản mặc định.
  4. Bấm nút Triển khai (Deploy) > Triển khai mới (New deployment) > Chọn Web app > Thực thi dưới dạng: Tôi > Ai có quyền: Bất kỳ ai > Sao chép Web App URL dán vào ô trên!
